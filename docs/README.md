# 截图放置说明

把三张截图放到本目录，文件名必须完全一致（README 里已经引用好了）：

| 文件名 | 拍什么 | 建议尺寸 |
|---|---|---|
| `1-drawer.png` | 左侧抽屉打开的样子（会话列表、搜索框、状态点） | 1170 × 2532（或任意竖屏 9:19.5） |
| `2-chat.png` | 对话正文 + 底部浮动输入卡 | 同上 |
| `3-theme.png` | 整屏效果（浅色主题、用户气泡靠右、工具卡单行） | 同上 |

要求：

- **不要出现任何真实项目名、会话标题、文件路径、正文内容** —— 可以先把会话重命名成「示例会话 A/B/C」，或者直接对敏感区域打码
- PNG 或 JPG 都行，单张控制在 500KB 以内
- 竖屏截图（手机原生比例），横屏会被 README 拉得很怪
