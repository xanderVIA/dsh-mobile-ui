# dsh-mobile-ui

**DSH 手机端界面增强** —— 给 `dsh-plugin-mobile-bridge` 的移动端页面做的一层界面改造：
把「一个能用但难受的网页」变成「像豆包 / DeepSeek 那样顺手的手机会话界面」。

> 不改宿主 DSH，不改插件的后端逻辑，只针对它吐出来的 `lib/mobile.html` 做注入。
> 插件升级后跑一次 `apply.ps1` 即可全部恢复。

> 截图已做像素化处理（模糊到不可读，只保留版式），不会暴露任何项目名或路径。
>

![对话](docs/s2-对话.png?v=3)

## 做了什么

### 导航
- 去掉底部四个页签（任务 / 新建 / 录音 / 余额），腾出约 90px
- 左上 `☰` 打开**左侧抽屉**：搜索框 + 常用/最近分组 + 每行 `⋯`（置顶 / 常用 / 删除）
- 右上 `＋` 新建会话；抽屉底部显示余额（取不到数字则整行隐藏）
- 会话名移到顶栏中间，随切换实时更新；顶栏默认自动收起

### 视觉
- 浅色主题（照豆包 / DeepSeek）：白底、无描边、单一强调色 `#1a6dff`
- 助手正文直接落在页面上（不套气泡）；用户消息淡蓝气泡，靠右、最宽 80%
- 复制按钮：我发的在右、助手发的在左
- Markdown 块级渲染：标题 / 列表 / 分隔线 / 引用 / 段落间距
- 图片一律缩略图（助手 ≤150px、自己发的 ≤110×150），`object-fit: contain` 不变形
- 表格窄屏卡片化（表头变成单元格上的小灰标）

![主题](docs/s3-主题.png?v=3)

### 运行态
- 输入卡里显示 `深度求索中，用时 m:ss`
- 运行中只保留最后一条工具行（纯 class 切换，不搬节点 → 页面不抽搐）
- 跑完显示 `已完成 · N 步`，可点开
- 会话抽屉：在跑的转圈、其余绿勾，每 2 秒刷新

### 输入区
- 浮动圆角卡片（离边 10px、24px 圆角、柔和投影）
- 待发图片：68×68 正方形缩略图，右上角大 ✕
- 键盘弹出时自动顶到底，不再被输入法遮挡

### 手势与返回
- 左右滑动换页已禁用（页签都没了，滑只会误触）
- 安卓返回键：先关抽屉 / 面板，再退桌面
- 悬浮控件在打开任何面板时自动让位
- 查看器：明显**向下拉**（>110px）关闭

## 怎么用

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File ".\apply.ps1"
```

它会：

1. **注入前**跑 `node --check ui.js`，语法不通过直接中止（页面保持原样）
2. 清掉上一次注入的内容（幂等，重复跑不会叠加）
3. 把 `ui.css` + `ui.js` 合成一个 `<style id="dsh-ui">` / `<script id="dsh-ui">`，追加到 `mobile.html` 末尾
4. 触发插件重载

改完在**左侧抽屉右上角**能看到构建号 `UI MM-DD HH:mm:ss` —— 时间戳变了才说明新代码在跑。

### 路径

`apply.ps1` 里这行写死了目标文件，按需修改：

```powershell
$Target = '<插件安装目录>\lib\mobile.html'
```

## 文件

| 文件 | 说明 |
|---|---|
| `ui.css` | 全部样式，33 节，按功能分段注释 |
| `ui.js` | 全部运行时逻辑，20+ 个模块，每个 `try/catch` 隔离 |
| `apply.ps1` | 注入脚本（幂等 + 注入前语法自检） |

## 已知问题

1. **查看器翻页动画**：试过三种做法都会和插件"重建 `<img>`"冲突（`display:none` 坏手势、`visibility` 坏布局、`transform` 让图落到屏外），最终放弃。要做得改插件的渲染函数，改成双图叠放。
2. **计时精度**：手机端拿不到"本轮开始时间"，只能用本地秒表或桥的会话累计时间。要完全同步需要插件在 `/api/boot` 多返回 `turnStartedAt`。
3. **僵尸 running 标记**：宿主偶尔在某轮异常结束后仍把 `summary.running` 留在 `true`，会话列表会一直转圈。进那个会话跑完一轮或重启 DSH 即可清。

## 踩过的坑（写给以后的自己）

| 事故 | 原因 | 现在怎么防 |
|---|---|---|
| 界面"空了一半"（控件全没） | `ui.js` 一个字符语法错，整块 `<script>` 被浏览器丢弃，CSS 却照常生效 | 注入前 `node --check`，不通过 `exit 1` |
| 白底白字（引用块/加粗看不见） | 深色主题的 `color:#fff` 残留 | 统一改为继承 / 深灰 |
| 图片"放大很多倍" | 图以原始像素 1200×2670 插入，屏幕只有 ~400 CSS px | `img { max-width:100%; max-height:42vh }` 兜底 |
| 改完"没反应" | 插件把 `mobile.html` 缓存在内存里 | 改完先 `curl` 服务端确认规则在里面 |
| 注入点失效 | 插在最后一个 `</body>` 前，那个 `</body>` 可能在某段字符串模板里 | 改为追加到文件末尾 |
| 页面抽搐 | 把散落的工具行搬进 `<details>`，DOM 重排导致滚动位置被拽 | 折叠改用 CSS `display`，不搬节点 |
